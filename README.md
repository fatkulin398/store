# ploika.uz — интернет-магазин + мини-приложение в Telegram

Один и тот же сайт работает двумя способами:

- **как обычный сайт** — открывается по ссылке в браузере (удобно ставить в шапку Instagram);
- **как мини-приложение внутри Telegram-бота** — покупатель выбирает товары, оформляет заказ, а бот присылает вам карточку заказа с кнопками «Подтвердить» / «Отменить».

Что есть в магазине: главная с новинками и хитами, категории, поиск, сортировка, страница товара, избранное, корзина, бесплатная доставка от заданной суммы, оформление заказа (имя, телефон, район Ташкента, адрес, способ оплаты).

```
store/
├── webapp/            ← сайт (его выкладываем на GitHub Pages)
│   ├── index.html
│   └── products.json  ← ВАШИ ТОВАРЫ, ЦЕНЫ И КОНТАКТЫ — редактируете только этот файл
└── bot/               ← Telegram-бот (запускается на сервере)
    ├── bot.py
    ├── requirements.txt
    └── .env.example
```

## 1. Заполните свои товары — `webapp/products.json`

Сейчас там 12 примерных товаров. Для каждого товара:

| Поле | Что писать |
|---|---|
| `id` | уникальный код, например `p013` |
| `name`, `brand`, `description` | название, бренд, описание |
| `category` | один из `id` в списке `categories` (`curling`, `dryers`, `brushes`, `straighteners`, `stylers`, `accessories`) |
| `price` / `old_price` | цена в сумах; `old_price` — старая цена для скидки (или `0`) |
| `image` | путь к фото, например `images/auto-curl.jpg` (положите файл в `webapp/images/`). Пусто — будет рисованная иконка |
| `tags` | `"new"` — в «Новинки», `"hit"` — в «Хиты продаж» |
| `stock` | сколько штук в наличии |

В блоке `store` укажите телефон, username бота (без @), Instagram, стоимость доставки и сумму, от которой доставка бесплатная.

Фото лучше квадратные, 1000×1000, до 300 КБ.

## 2. Выложите сайт на GitHub Pages (бесплатно)

1. Создайте репозиторий на GitHub, например `store`, и загрузите туда всю папку.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Workflow `.github/workflows/pages.yml` уже лежит в проекте и сам опубликует папку `webapp`.
3. Через 1–2 минуты сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/store/`.

После каждого изменения `products.json` на GitHub сайт обновится сам.

## 3. Создайте бота

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя и username. Сохраните токен.
2. Там же: `/mybots` → ваш бот → **Bot Settings → Configure Mini App → Enable Mini App** → вставьте адрес сайта из шага 2.
3. По желанию: `/setuserpic` (логотип), `/setdescription` (описание), `/setcommands`:
   ```
   start - Открыть магазин
   contacts - Контакты и доставка
   ```

## 4. Запустите бота и админ-панель на Railway

Бот и сервер админ-панели — одна программа (`bot/bot.py`). В репозитории уже есть `railway.json`.

1. railway.com → **New Project → Deploy from GitHub repo → fatkulin398/store**.
2. **Volume** (база заказов, чтобы они не пропадали при перезапуске): в проекте нажмите на сервис → **⋮ → Attach Volume**, путь `/data`.
3. **Variables** — добавьте:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `WEBAPP_URL` | `https://fatkulin398.github.io/store/` |
| `ADMIN_PASSWORD` | придуманный пароль для входа в админ-панель |
| `DATA_DIR` | `/data` |
| `GITHUB_TOKEN` | ключ GitHub для редактирования каталога (см. ниже) |
| `ADMIN_CHAT_ID` | ID чата для заказов — после первого запуска напишите боту `/id` |

4. **Settings → Networking → Generate Domain** — получите адрес вида `https://store-production-xxxx.up.railway.app`.
5. Откройте `https://fatkulin398.github.io/store/admin.html`, впишите этот адрес и пароль. В админке: **Каталог → Магазин и доставка → Адрес сервера** — вставьте тот же адрес и сохраните. После этого заказы с сайта попадают прямо в «Продажи».

**Ключ GitHub (`GITHUB_TOKEN`)** — нужен, чтобы менять товары из админки:
github.com → Settings → Developer settings → Personal access tokens → **Fine-grained tokens → Generate new token** →
Repository access: **Only select repositories → store** → Permissions: **Contents — Read and write** → Generate.
Скопируйте ключ сразу в Railway (Variables). Никому его не присылайте.

## Админ-панель

`https://fatkulin398.github.io/store/admin.html` — работает с телефона и компьютера.

- **Главное** — выручка и заказы за сегодня в сравнении со вчера, график за 7 дней, заказы, которые ждут подтверждения, товары, которые заканчиваются.
- **Продажи** — все заказы с фильтром по статусу и периоду, поиск по номеру, имени, телефону, адресу. В карточке заказа — смена статуса (Новый → Подтверждён → Доставляется → Выполнен / Отменён); покупатель получает сообщение в Telegram.
- **Каталог** — товары (фото, цены, скидки, остатки, «Новинка» / «Хит»), категории, настройки магазина и доставки. Изменения применяются кнопкой «Сохранить», на сайте — через 1–2 минуты.
- **Клиенты** — все покупатели: сколько заказали и потратили, история заказов, звонок в один клик.
- **Аналитика** — выручка, заказы, средний чек и сравнение с прошлым периодом; топ товаров; продажи по категориям, районам, способам оплаты; откуда приходят заказы; в какие часы заказывают.

## Как проходит заказ

1. Покупатель открывает магазин (сайт или кнопка «🛍 Открыть магазин» в боте), собирает корзину и оформляет заказ.
2. Сервер пересчитывает сумму по актуальному каталогу и сохраняет заказ — он сразу появляется в «Продажах».
3. Вам приходит карточка заказа в Telegram с кнопками смены статуса, покупателю — подтверждение (если заказ из Telegram).

## Проверить сайт у себя на компьютере

```bash
cd webapp
python -m http.server 8000
```
и откройте http://localhost:8000. Просто двойной клик по `index.html` не сработает — браузер не даст загрузить `products.json`.
