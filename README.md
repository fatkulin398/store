# ploika.uz — интернет-магазин + мини-приложение в Telegram

Один и тот же сайт работает двумя способами:

- **как обычный сайт** — открывается по ссылке в браузере (удобно ставить в шапку Instagram);
- **как мини-приложение внутри Telegram-бота** — покупатель выбирает товары, оформляет заказ, а бот присылает вам карточку заказа с кнопками «Подтвердить» / «Отменить».

Что есть в магазине: главная с новинками и хитами, категории, поиск, сортировка, страница товара, избранное, корзина, бесплатная доставка от заданной суммы, оформление заказа (имя, телефон, район Ташкента, адрес, способ оплаты).

```
store/
├── webapp/            ← сайт (его выкладываем на GitHub Pages)
│   ├── index.html
│   └── products.json  ← ВАШИ ТОВАРЫ, ЦЕНЫ И КОНТАКТЫ — редактируете только этот файл
└── bot/               ← Telegram-бот (запускается на сервере)
    ├── bot.py
    ├── requirements.txt
    └── .env.example
```

---

## 1. Заполните свои товары — `webapp/products.json`

Сейчас там 12 примерных товаров. Для каждого товара:

| Поле | Что писать |
|---|---|
| `id` | уникальный код, например `p013` |
| `name`, `brand`, `description` | название, бренд, описание |
| `category` | один из `id` в списке `categories` (`curling`, `dryers`, `brushes`, `straighteners`, `stylers`, `accessories`) |
| `price` / `old_price` | цена в сумах; `old_price` — старая цена для скидки (или `0`) |
| `image` | путь к фото, например `images/auto-curl.jpg` (положите файл в `webapp/images/`). Пусто — будет рисованная иконка |
| `tags` | `"new"` — в «Новинки», `"hit"` — в «Хиты продаж» |
| `stock` | сколько штук в наличии |

В блоке `store` укажите телефон, username бота (без @), Instagram, стоимость доставки и сумму, от которой доставка бесплатная.

Фото лучше квадратные, 1000×1000, до 300 КБ.

## 2. Выложите сайт на GitHub Pages (бесплатно)

1. Создайте репозиторий на GitHub, например `store`, и загрузите туда всю папку.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Workflow `.github/workflows/pages.yml` уже лежит в проекте и сам опубликует папку `webapp`.
3. Через 1–2 минуты сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/store/`.

После каждого изменения `products.json` на GitHub сайт обновится сам.

## 3. Создайте бота

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя и username. Сохраните токен.
2. Там же: `/mybots` → ваш бот → **Bot Settings → Configure Mini App → Enable Mini App** → вставьте адрес сайта из шага 2.
3. По желанию: `/setuserpic` (логотип), `/setdescription` (описание), `/setcommands`:
   ```
   start - Открыть магазин
   contacts - Контакты и доставка
   ```

## 4. Запустите бота

Нужен компьютер или сервер, который работает постоянно (подойдёт недорогой VPS, Railway, Render или PythonAnywhere).

```bash
cd bot
pip install -r requirements.txt
cp .env.example .env      # заполните BOT_TOKEN и WEBAPP_URL
python bot.py
```

Узнать `ADMIN_CHAT_ID`: напишите боту `/id` — в личке или в группе менеджеров, куда должны приходить заказы (бота нужно добавить в группу). Впишите число в `.env` и перезапустите бота.

Бот читает цены из `../webapp/products.json`. Если бот работает на отдельном сервере, укажите в `.env` путь к копии файла: `PRODUCTS_PATH=/путь/к/products.json`. Сумму заказа бот всегда пересчитывает по своему файлу.

## Как проходит заказ

1. Покупатель жмёт `/start` → кнопку **«🛍 Открыть магазин»** внизу экрана.
2. Выбирает товары, в корзине нажимает большую кнопку Telegram «Оформить», заполняет форму, «Отправить заказ».
3. Покупатель получает в чате подтверждение с составом и суммой, вы — карточку заказа с кнопками.
4. Нажимаете «Подтвердить» или «Отменить» — бот сам пишет покупателю.

> Заказ уходит боту напрямую только из кнопки «🛍 Открыть магазин» внизу чата — так устроен Telegram. Если покупатель открыл магазин через кнопку «Магазин» слева от поля ввода или как обычный сайт, после оформления текст заказа копируется, и открывается чат с ботом, чтобы отправить его вам.

## Проверить сайт у себя на компьютере

```bash
cd webapp
python -m http.server 8000
```
и откройте http://localhost:8000. Просто двойной клик по `index.html` не сработает — браузер не даст загрузить `products.json`.
